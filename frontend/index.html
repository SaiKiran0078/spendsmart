Your money data deserves real security

SpendSmart is built with the same practices used in production web apps, and the whole codebase is open for you to read.

  • Passwords hashed with bcrypt, never stored in plain text
  • Expiring JWT sessions and rate-limited sign-in against brute force
  • Every record is scoped to its owner, so other users can never see yours
  • Strict input validation, a content-security policy and safe CSV handling
  • Delete your account and all its data at any time
